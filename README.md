# Rebar Optimizer Pro

هذا المشروع عبارة عن أداة **احترافية لتوزيع الحديد وتقليل الهدر**، مع إنشاء تقرير PDF شامل لكل التفاصيل.  

---

## مميزات المشروع

1. **MainBar** – جدول جميع القضبان المدخلة مع الوزن الإجمالي.
2. **WasteBar** – جدول الهدر لكل قطر، مع مجموع وزن الهدر.
3. **PurchaseBar (12m Bars)** – جدول يوضح عدد القضبان المطلوبة بطول 12 متر، مع الوزن والكلفة الإجمالية.
4. **Cutting Instructions** – أفضل طريقة قص القضبان باستخدام **ILP** لتقليل الهدر وعدد القضبان المطلوبة.
5. **PDF Report** – إمكانية تنزيل تقرير PDF جاهز يحتوي على كل الجداول السابقة.
